## 下载地址

可从以下平台下载 Remote Bot Fetch：

- [GitHub Releases](https://github.com/SGU-Server/Remote-Bot-Fetch/releases)
- [Modrinth](https://modrinth.com/mod/remote-bot-fetch/versions)
- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/remote-bot-fetch/files)

请选择与你的 Minecraft 版本相匹配的文件。客户端和服务端均可安装使用。

## 依赖

本模组仅支持 Fabric。

请先安装 [Fabric Loader](https://fabricmc.net/use)，再安装以下依赖：

- Fabric API（[GitHub Releases](https://github.com/FabricMC/fabric-api/releases)、[Modrinth](https://modrinth.com/mod/fabric-api)、[CurseForge](https://www.curseforge.com/minecraft/mc-mods/fabric-api)）
- Fabric Carpet（[GitHub Releases](https://github.com/gnembon/fabric-carpet/releases)、[Modrinth](https://modrinth.com/mod/carpet)、[CurseForge](https://www.curseforge.com/minecraft/mc-mods/carpet)）
- MaLiLib（[GitHub Releases](https://github.com/Sakura-ryoko/malilib/releases)、[Modrinth](https://modrinth.com/mod/malilib)、[CurseForge](https://www.curseforge.com/minecraft/mc-mods/malilib)）

如果只需要服务端功能，且希望使用更轻量的方案，可以改用 [Remote Bot Fetch Server](https://github.com/SGU-Server/Remote-Bot-Fetch-Server/releases)。它仅依赖 Fabric Carpet（[GitHub Releases](https://github.com/gnembon/fabric-carpet/releases)、[Modrinth](https://modrinth.com/mod/carpet)、[CurseForge](https://www.curseforge.com/minecraft/mc-mods/carpet)）。
